Deterministic vs assistive

Everything in the table above commits business state. Anything involving judgment — summarizing a request, proposing duplicates, drafting a narrative — is an agent suggestion a person confirms.

Wave 0

Groups and access policies

Group names are the product role model. Membership is yours. Financial, board, and commercial data is restricted by policy, not by convention.

Groups

RequestersProduct OwnersPlatform OwnersEngineering LeadsArchitectsSecurity ReviewersFinance PartnersBenefit OwnersInvestment BoardGovernance Admins

Access policy intent

  • Requesters see their own demand, not portfolio financials
  • Financial and funding fields limited to finance, board, and PMO
  • Vendor commercial data limited to vendor and sourcing owners
  • Gate waivers visible to architecture and security reviewers
  • Only governance admins edit configuration elements

Wave 8 · after records are trustworthy

Agents and their tools

Three assistive agents. Each has explicitly scoped tools, and any state change goes through a published automation a person triggers or confirms.

Triage assistant

Agent

Tools: search Demand, search Portfolio Item, search work-management table.

Produces: draft summary, suggested type and product, confidence-scored duplicate candidates, backlog-versus-investment recommendation.

Cannot: set disposition or reject demand.

Board pack drafter

Agent

Tools: search Portfolio Item, Cost Line, Milestone, Risk.

Produces: narrative sections from live portfolio data; challenges an incomplete case or unsupported cost assumption.

Cannot: record a board decision.

Outcome chaser

Agent

Tools: search Outcome Record, telemetry table.

Produces: overdue measurement chases, challenges to value claims with no movement in source data.

Cannot: mark value realized.
