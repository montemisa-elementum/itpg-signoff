# IT Portfolio & Governance (ITPG)

Visual Elementum solution planning for the eight-application **IT Portfolio & Governance** suite described by the client workbook.

## Sign-off site (for people)

Open [`index.html`](index.html) in a browser. No server, package install, or internet connection is required.

| Page | Contents |
|---|---|
| [`index.html`](index.html) | Workbook-aligned eight-app proposal, cross-app flows, candidate AspectTasks, app detail, client inputs and validation questions |
| [`site/config.html`](site/config.html) | Representative cross-app automations, access policy and agent boundaries |
| [`site/pm.html`](site/pm.html) | Requirement counts, pain-point evidence, acceptance framework and missing process input |

The current homepage is rendered from [`site/eight-apps.js`](site/eight-apps.js). The earlier two-spine dataset remains in [`site/explorer.js`](site/explorer.js) for comparison and git history.
